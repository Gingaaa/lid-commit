# Security Policy

We actively provide security updates and patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :x:                |

---

## Reporting a Vulnerability

The LidCommit team takes security seriously. If you discover a security vulnerability (such as API key exposure, command injection, or power broadcast interception issues):

1. **DO NOT** create a public GitHub issue.
2. Please send a direct, confidential email to the project maintainer at:
   **anshusee22@gmail.com**
3. Include detailed steps to reproduce the vulnerability, including:
   - Your operating system and LidCommit version
   - Code samples or steps to reproduce
   - Potential impact
4. You will receive an acknowledgment within 48 hours with next steps and remediation timelines.
